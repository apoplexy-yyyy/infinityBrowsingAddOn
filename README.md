# Infinite Zoom Browser

スクロールアップで拡大、ダウンで縮小するブラウザ拡張です。リンクが十分に大きくなると、その場所にリンク先のページが現れ、さらに拡大して奥へ入っていけます。

## 拡張を入れずに試す

`index.html` をブラウザで開くと、内蔵のサンプルサイトで操作を試せます。スマホではピンチで拡大・縮小、1本指で移動、タップでリンクを開きます。実在のサイトは拡張機能でなければ表示できません。

## インストール(Chrome / Edge)

1. `chrome://extensions`(Edge は `edge://extensions`)を開く
2. 「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 使い方

http / https のページで拡張アイコンを押すと、そのタブが無限ズーム表示に切り替わります。

| 操作 | 動作 |
| --- | --- |
| ホイール上 / 下 | カーソル位置を中心に拡大 / 縮小 |
| ドラッグ&ドロップ | ページ内を移動 |
| リンクをクリック | 拡大したときと同じようにリンク先を開く(Ctrl などを押しながらのクリックはブラウザの通常動作) |
| ボタンなどをクリック | 通常どおり操作 |
| 重なりを許可 | オフ(初期設定)ではページの外側の右横に、オンではリンクの右横にページへ重ねてリンク先を表示 |
| カード右上の × | そのリンク先を閉じる(中で開いたカードも一緒に閉じる) |
| ⟲ / ↗ / ✕ | 最初に戻る / 新しいタブで開く / 終了して表示中のページへ移動 |

拡大すると、画面中央に最も近いリンクが1つだけ開きます。表示位置は「重なりを許可」の設定に従い、どちらの設定でも同じページから開いたカード同士は押し合って重なりません。開いたリンク先は縮小しても表示され続け、カードの × を押したとき、親ページが別のページへ移動したとき、⟲ を押したときにだけ閉じます。× で閉じたリンクは、そのまま拡大しても開き直さず、クリックするか、一度縮小してから拡大すると開きます。

ページはスクロール先まで含めた縦長のカードとして表示されるので、縮小するとページ全体を見渡せます。

ページの末尾が画面に近づくと、次のページの本文を自動で読み込んで継ぎ足し(オートページャ)、カードがさらに縦長になります。継ぎ足した部分のリンクも同じように拡大して開けます。

## 制限事項

- オートページャの対象は、同じサイト内に次のページへのリンク(`rel="next"` や「次へ」など)があるページです。本文の位置はページ同士の比較で推定するので、サイトによっては余分な部分が混ざったり、継ぎ足せなかったりします。1枚のカードで継ぎ足すのは100ページまでです。
- 継ぎ足した部分ではページのスクリプトは動きません。
- カードの高さは表示位置に合わせて広がり、最大 500000px です。これより長いページや、高さが画面に連動するページでは、残りをドラッグでスクロールします。
- 画面いっぱいの枠の中だけをスクロールするアプリ型のサイトは、縦長に広がりません。

- 埋め込みを許可しないサイトも表示できるよう、**無限ズーム中のタブのサブフレームに限り** `X-Frame-Options` と `Content-Security-Policy` を除去します。他のタブには影響しません。
- 埋め込みを自前のスクリプトで検出して表示を止めるサイトや、ログインをブロックするサイトは正しく表示できないことがあります。
- ページ内の iframe(動画の埋め込みなど)は、ズーム操作を優先するため操作できません。
- ドラッグが移動に割り当てられているため、入力欄以外のテキストは選択できません。
